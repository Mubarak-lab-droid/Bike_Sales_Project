# 🍕 Pizza Sales Performance Analysis

Analysis of a full year of pizza sales transactions (2015) using Excel — from raw data cleaning to an interactive dashboard.

## What's in this project
- Raw transactional data: order details, pizza type, size, category, pricing, and timestamps
- Pivot tables and calculated metrics (revenue, average order value, quantity trends)
- Interactive dashboard with slicers for pizza size, day of week, and category

## Key Insights
- **Total Revenue:** $817,860.05 across 21,350 orders
- **Top-selling pizza:** The Classic Deluxe Pizza (2,453 orders)
- **Revenue by size:** Large pizzas made up 45.9% of total sales
- **Peak order time:** 12 PM, with Thursday as the busiest day
- **Average Order Value:** $38.31

## Tools Used
Excel — Pivot Tables, Pivot Charts, Slicers, Dashboard Design
